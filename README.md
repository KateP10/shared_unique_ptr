
# Домашнее задание №1 - Умные указатели
Реализация умных указателей на C++ без использования STL (кроме сравнительного тестирования). Демонстрация автоматического управления памятью и отсутствия утечек.
## Что реализовано
- **UnqPtr<T>** - умный указатель с исключительным владением (аналог std::unique_ptr). Копирование запрещено, перемещение разрешено. Поддерживает подтипизацию UnqPtr<Derived> -> UnqPtr<Base>.
- **ShrdPtr<T>** - умный указатель с разделяемым владением (аналог std::shared_ptr). Ведёт счётчик ссылок через поле size_t* refCount_. Поддерживает подтипизацию и корректно делит один счётчик между несколькими указателями.
- **SharedArray<T>** — контейнер на ShrdPtr<T>, демонстрирующий практическое применение.
- **Тесты корректности** — подтипизация, отсутствие утечек, работа в контейнере, граничные случаи.
- **Бенчмарки** — сравнение времени работы и теоретического расхода памяти для сырых указателей, UnqPtr, ShrdPtr и STL std::shared_ptr.
### Назначение файлов
- **main.cpp** — вызывает функции тестов и бенчмарков. 
- **tests.h** — прототипы функций test_ и bench_. 
- **tests.cpp** — определения тестовых структур (Base, Derived, Tracked), функциональных тестов и замеров производительности.
- **unique_ptr.h, shared_ptr.h, array.h** — шаблонные классы.

##### Тесты
test_unq_subtyping - проверяет подтипизацию UnqPtr
test_shrd_subtyping - проверяет подтипизацию ShrdPtr и корректность общего счетчика
test_no_leak - проверяет отсутствие утечек через счетчик живых объектов Tracked::alive
test_container - проверяет SharedArray и shared ownership в контейнере
bench_table - замеряет время создания и удаления N объектов
print_memory_table - считает теоретический расход памяти
